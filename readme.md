# My CV

Previously built with Latex (see `latex` tag). Now, completely rewrote using web
tech.

## Run locally

Requires [mise][mise], which installs [bun][bun] and runs the tasks.

```sh
mise install
bun install
mise dev      # dev server
```

Run `mise tasks` for build, preview, lint, format, and PDF generation.
